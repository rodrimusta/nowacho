# Respuestas rápidas para WhatsApp Business – Venta de pasajes

Todo lo que está entre `[corchetes]` hay que reemplazarlo por el dato real.

## Cómo cargarlas

**Respuestas rápidas:** WhatsApp Business → Configuración → Herramientas para la empresa → Respuestas rápidas → `+`.
- En "Mensaje" pegás el texto.
- En "Atajo" ponés la palabra (sin la `/`).
- Después, en cualquier chat, escribís `/` y el atajo, y se pega el texto.
- Funciona también en **WhatsApp Web** desde la compu, que con 200 chats por día es mucho más rápido que el celular.

**Bienvenida y ausencia:** Herramientas para la empresa → Mensaje de bienvenida / Mensaje de ausencia.

---

## 1. Mensaje de bienvenida (automático)

Es el cambio más importante: pide todos los datos de una, así no hay ida y vuelta.

```
¡Hola! 👋 Gracias por escribir a 20 de Junio.
Para cotizarte más rápido, mandame en un solo mensaje:

📍 Origen y destino
📅 Fecha de viaje (y si es ida y vuelta, fecha de regreso)
🕐 Horario aproximado (mañana / tarde / noche)
👥 Cantidad de pasajeros

En unos minutos te respondo con horarios y precios.
```

## 2. Mensaje de ausencia (fuera de horario)

```
¡Hola! En este momento estamos fuera del horario de atención.
Atendemos de [lunes a sábado de 8 a 20 hs].
Dejanos origen, destino, fecha y cantidad de pasajeros, y te respondemos apenas abramos. ¡Gracias!
```

## 3. Respuestas rápidas

### `/datos` – Pedir datos (si no los mandaron)
```
¡Hola! Para cotizarte necesito:
📍 Origen y destino
📅 Fecha de viaje
👥 Cantidad de pasajeros
```

### `/horarios` – Horarios de un tramo
Conviene crear una por cada tramo que más te piden (`/hrosario`, `/hbsas`, etc.).
```
🚌 Horarios [Origen] → [Destino]:
• [06:00]
• [10:30]
• [15:00]
• [19:45]
¿En cuál te gustaría viajar?
```

### `/precio` – Precio
Igual que los horarios: una por tramo frecuente (`/prosario`, etc.).
```
💲 [Origen] → [Destino]: $[precio] por pasajero.
[Ida y vuelta: $precio]
¿Te reservo el pasaje? Pasame nombre completo y DNI de cada pasajero.
```

### `/pasajeros` – Pedir datos para emitir
```
Perfecto. Para emitir el pasaje necesito de cada pasajero:
• Nombre y apellido
• DNI
Y confirmame fecha y horario.
```

### `/pago` – Formas de pago
```
Podés pagar por:
💳 [Transferencia — Alias: XXXXX / CBU: XXXXX / Titular: XXXXX]
💵 [Efectivo en boletería]
Cuando transfieras, mandame el comprobante y te envío el pasaje.
```

### `/enviado` – Entrega del pasaje
```
✅ ¡Listo! Te envío tu pasaje.
Presentate en [terminal / andén] [30] minutos antes de la salida, con tu DNI.
¡Buen viaje! 🚌
```

### `/terminal` – Dónde se toma el colectivo
```
📍 [Ciudad]: [Terminal, dirección, boletería/andén].
📍 [Ciudad]: [Terminal, dirección].
```

### `/equipaje`
```
🧳 Cada pasajero puede llevar [1 bolso de hasta XX kg en bodega + 1 de mano].
[Exceso de equipaje / bultos especiales: consultar].
```

### `/menores`
```
👶 [Menores de X años viajan sin cargo sin ocupar asiento, presentando DNI].
[Menores de X años que viajan solos: requisitos].
```

### `/cambios` – Cambios y devoluciones
```
🔄 Podés cambiar o devolver el pasaje hasta [XX horas antes] de la salida.
[Condiciones / recargo].
Pasame el número de pasaje y lo vemos.
```

### `/sinlugar` – Sin disponibilidad
```
Uy, para ese horario ya no quedan lugares 😕
Tengo disponible:
• [Horario alternativo]
• [Otro día]
¿Te sirve alguno?
```

### `/espera` – Ganar tiempo
```
Dame un minutito que lo reviso en el sistema y te confirmo 🙌
```

### `/gracias`
```
¡Gracias a vos! Cualquier cosa, escribime por acá. ¡Buen viaje! 🚌
```

---

## 4. Etiquetas sugeridas

En WhatsApp Business podés etiquetar cada chat para no perder ninguno:

- 🟡 **Cotizado:** ya le pasaste el precio.
- 🟠 **Esperando pago:** confirmó, falta el comprobante.
- 🟢 **Vendido:** pasaje enviado.
- 🔴 **Pendiente:** te falta responder algo.

---

## 5. Más tips para ganar tiempo

- **Pasaje en PDF o captura en vez de foto:** si FICS deja imprimir o guardar el pasaje como PDF, mandá eso. Es más rápido y se ve mejor que la foto.
- **Catálogo:** cargá los tramos más vendidos con su precio (Herramientas para la empresa → Catálogo). Cuando te preguntan, mandás el producto con dos toques.
- **Estado del día:** publicá los horarios del día en tu Estado. Muchos lo ven antes de escribir.
- **Mensajes destacados:** marcá con ⭐ las respuestas largas que usás seguido para reenviarlas rápido.
